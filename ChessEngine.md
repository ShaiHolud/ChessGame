# Chess Engine Architecture

Версия: v1.0

---

# Назначение

ChessEngine — независимый игровой движок, реализующий правила шахмат.

Движок не зависит от:

- UI (WPF)
- REST API
- Telegram Bot
- AI

Любой внешний клиент работает только через публичный API класса Game.

# Основные классы

## Game

Game — единственная публичная точка входа в игровой движок.

Отвечает за:

- очередь хода;
- проверку легальности ходов;
- историю партии;
- Undo;
- шах;
- мат;
- пат;
- специальные правила;
- состояние игры.

Game ничего не знает о пользовательском интерфейсе.

---

## Board

Board отвечает исключительно за состояние доски.

Board НЕ знает:

- чей сейчас ход;
- что такое мат;
- что такое шах;
- правила партии.

Board умеет:

- добавить фигуру;
- удалить фигуру;
- переместить фигуру;
- откатить изменения.

---

## ChessPiece

Базовый класс всех фигур.

Хранит:

- цвет;
- позицию;
- количество ходов;
- состояние "жива".

Каждая фигура знает только собственную механику движения.

---

## MoveProvider

Каждая фигура получает допустимые ходы через MoveProvider.

Например:

PawnMoveProvider

KnightMoveProvider

BishopMoveProvider

...

MoveProvider ничего не знает о:

- шахе;
- очереди;
- истории.

Он лишь отвечает на вопрос:

> Куда эта фигура может пойти согласно правилам движения?

---

# Получение легальных ходов

Алгоритм:

1. Получить все возможные ходы фигуры.

2. Для каждого:

    выполнить временный ход;

    проверить шах своему королю;

    откатить ход.

3. Если шаха нет — ход считается легальным.

Таким образом все проверки шаха централизованы.

---

# История партии

История хранится в Game.
Stack<MoveState>

Каждый выполненный ход создаёт MoveState.

Undo никогда не вычисляет состояние доски.

Undo всегда восстанавливает ранее сохранённый MoveState.

---

# MoveState

MoveState хранит все изменения, произошедшие за один ход.

В настоящее время содержит:

- основную фигуру;
- исходную позицию;
- конечную позицию;
- предыдущий MoveCount;

при необходимости:

- взятую фигуру;
- позицию взятой фигуры;
- предыдущий MoveCount взятой фигуры;

для рокировки:

- вторую фигуру (ладья);
- её позиции;

для превращения:

- созданную фигуру.

MoveState является основой Undo.

---

# Undo

Undo работает по принципу:

последний ход

↓

MoveState

↓

полное восстановление позиции

Board не вычисляет прошлое состояние.

Board лишь выполняет инструкции MoveState.

---

# Проверка шаха

Алгоритм проверки:

найти короля

↓

получить все возможные ходы фигур соперника

↓

если одна из фигур атакует короля

↓

шах

---

# Мат

Мат определяется как
Король под шахом

И

нет легальных ходов.

---

# Пат

Пат определяется как
Король НЕ под шахом

И

нет легальных ходов.

---

# Специальные правила

Поддерживаются:

- рокировка;
- взятие на проходе;
- превращение пешки.

Все специальные правила выполняются через Game.

Board не принимает решений.

---

# Ответственность классов

Game

✔ правила игры

✔ история

✔ очередь

✔ победа

✔ ничья

Board

✔ состояние клеток

✔ перемещение фигур

✔ Undo

ChessPiece

✔ собственное движение

MoveProvider

✔ вычисление возможных ходов

---

# Принцип проектирования

Game принимает решения.

Board изменяет состояние.

ChessPiece знает только себя.

MoveProvider знает только геометрию движения.

# Инварианты движка

- На доске всегда ровно один белый король.
- На доске всегда ровно один чёрный король.
- Одна клетка содержит не более одной фигуры.
- Живая фигура всегда присутствует на доске.
- Захваченная фигура отсутствует на доске.
- Любое изменение доски должно быть обратимо через MoveState.
- Board не принимает решений о правилах игры.
- Game — единственная публичная точка входа в движок.
